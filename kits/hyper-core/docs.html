API Reference

All endpoints accept JSON payloads and require a Bearer token in the Authorization header.

List Deployments

Returns a paginated list of active deployments in your organization.

GET /v1/deployments
HTTP Request
curl -X GET https://api.hypercore.sys/v1/deployments \
  -H "Authorization: Bearer hc_live_..."

Create Deployment

Triggers a new build and deploy sequence for the specified repository.

POST /v1/deployments
Request Body
{
  "project_id": "proj_9f8a2b1",
  "branch": "main",
  "env_vars": {
    "NODE_ENV": "production"
  }
}
Response 200 OK
{
  "id": "dep_8f7d6e",
  "status": "queued",
  "created_at": "2026-11-15T14:32:00Z"
}
