# Orbital — Space Dark Kit

A sci-fi inspired multi-page dashboard and landing page kit. Features a dark cosmic theme, neon cyan accents, Space Grotesk typography, and a fully functional CSS-only starfield.

## Pages

| Page | File | Purpose |
|------|------|---------|
| Landing | `index.html` | Hero section + feature grid |
| Dashboard | `dashboard.html` | Sidebar layout + stats + data table |
| Pricing | `pricing.html` | 3 tiers (Cadet, Commander, Fleet) |
| Auth | `auth.html` | System login / access portal |
| 404 | `404.html` | Animated orbital "Signal Lost" page |

## Design Tokens

Modify `assets/styles.css` `:root` variables to change the theme.

```css
--primary: #00f0ff;   /* Cyan neon */
--secondary: #ff0055; /* Magenta */
--bg: #05050a;        /* Deep space */
